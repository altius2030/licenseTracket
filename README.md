# License Tracker

Приложение для отслеживания сроков действия лицензий под Windows.

## Особенности

- 📊 **Локальная база данных** (SQLite) - данные хранятся на вашем компьютере
- 📑 **Поддержка множественных листов Excel** - каждый лист отображается как отдельная вкладка
- 🎴 **Карточки пользователей** - полноценное редактирование всех полей
- 🎨 **Автостатус + ручное переопределение** - автоматический расчет статуса (Активна/Скоро истекает/Истекла) с возможностью ручной корректировки
- 📥📤 **Импорт/Экспорт Excel** - работа с вашей текущей базой "База Данных.xlsx"
- 🔍 **Поиск и фильтрация** - по имени, магазину, телефону, статусу
- 🌙 **Темная/светлая тема** - современный интерфейс на CustomTkinter

## Структура базы данных

Приложение автоматически создает SQLite базу с полями, покрывающими все ваши листы:
- **GBS** - основные поля: дата установки, ФИО, магазин, телефон, почта, GBS ID, срок активации, срок ID, даты оплат, адрес
- **ШопУчет** - ФИО, магазин, ключ, дата оплаты
- **шоп учет / АСТАНА / Алматы / отвалы** - расширенные поля: отправлено, активация, оплата, квитанции, комментарии

## Установка и запуск

### Вариант 1: Через Python (рекомендуется)
```bash
cd LicenseTracker
python run.py
```

### Вариант 2: Прямой запуск
```bash
cd LicenseTracker
pip install -r requirements.txt
python main.py
```

### Вариант 3: Создание .exe (для распространения)
```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name "LicenseTracker" --icon=icon.ico main.py
```
Готовый .exe будет в папке `dist/`.

## Использование

1. **Первый запуск** - приложение создаст пустую базу `licenses.db`
2. **Импорт данных** - нажмите "📥 Импорт Excel" и выберите ваш файл `База Данных.xlsx`
3. **Работа с данными** - переключайтесь вкладками листов, используйте поиск и фильтры
4. **Редактирование** - двойной клик по строке или правый клик → "Редактировать"
5. **Статусы** - в карточке лицензии виден автостатус и можно задать ручной
6. **Экспорт** - "📤 Экспорт Excel" сохранит текущий вид (или все листы) в файл

## Горячие клавиши

- `Delete` - удалить выделенные записи
- `Double Click` - редактировать запись
- `Right Click` - контекстное меню

## Файлы проекта

## Требования

- Windows 10/11
- Python 3.9+ (если запускаете из исходников)
- Зависимости: `customtkinter`, `openpyxl`, `pandas`, `python-dateutil`

## Импорт вашей текущей базы

Приложение уже настроено под структуру вашего файла `База Данных.xlsx`:
- Листы: GBS, ШопУчет, шоп учет, АСТАНА, Алматы, отвалы
- Все колонки распознаны и замаплены на поля БД
- Даты парсятся в разных форматах (ДД.ММ.ГГГГ, ISO, Excel serial)

Просто нажмите "Импорт Excel" и выберите ваш файл.
